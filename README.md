## Atividade Prática — CRUD de Cadastro de Alunos em Vue 3

Aluna: Daniele Senko de Lima

1. Objetivo
Construir um pequeno CRUD (Create / Read / Update / Delete) de Cadastro de Alunos em Vue 3 com
<script setup> (Composition API), aplicando obrigatoriamente todas as diretivas vistas em sala:
ref() , interpolação {{ }} , v-if , v-else , v-show , v-for (mais v-model e @click já
usados).
